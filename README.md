1) git --version :-

The git --version command is used to identify the currently installed version of Git on your system. It is a built-in utility essential for verifying successful installation and checking feature compatibility.

2) git clone <--File Link--> :-

The git clone command is used to create a local copy of an existing remote Git repository. Unlike simply downloading a project ZIP file, cloning includes the entire project history, all branches, and version control metadata. 

3) git Status :- 

The git status command is used to display the current state of the working directory and the staging area. It is a read-only command that provides a snapshot of changes without modifying your repository(Display the State of The Code).

4) git add <- file name -> :-

adds new or changed files in your working directory to the Git staging area. The git add command is used to move changes from your working directory to the staging area (also known as the "index"), preparing them to be included in the next commit.



5) git commit -m "some message" :-

it is the record of change. The git commit command is used to save a snapshot of the project's current staged changes to the local repository. Unlike other version control systems, a Git commit only saves changes locally; you must use git push to share these changes with a remote server. 


6) git push origin main :-

upload local repo content to remote repo. The git push command uploads local repository commits to a remote repository, such as GitHub or GitLab, making your changes available to others. 


7) mkdir :- 

The mkdir command is not actually a part of the Git toolset. Instead, it is a standard operating system command (short for "make directory") used within terminals like Git Bash or Linux/Unix shells to create new folders on your computer.
